# 🚦 SmartTraffic

## Présentation

SmartTraffic est un projet académique de simulation et de gestion
intelligente du trafic routier, développé en Java.

## Objectifs

- Simuler la circulation routière.
- Optimiser la gestion des feux de signalisation.
- Réduire la congestion et les temps d'attente.
- Gérer la priorité des véhicules d'urgence.

## Technologies

- Java
- Maven
- JavaFX
- JUnit
- Git et GitHub

## Organisation du projet

Le projet est réalisé par une équipe de sept membres.
Chaque membre développe son module sur une branche dédiée.

## Installation

Cloner le repository :

```bash
git clone https://github.com/hibaelahmadi/SmartTraffic.git
```

Accéder au projet :

```bash
cd SmartTraffic
```

Compiler le projet :

```bash
mvn clean compile
```

Exécuter les tests :

```bash
mvn test
```

## Organisation des branches

- `main` : branche principale du projet.
- `feature/intelligent-traffic` : module de gestion intelligente du trafic.
- `feature/nom-du-module` : branches des autres membres.
